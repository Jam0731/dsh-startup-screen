# dsh-startup-screen · 声音增强版

DeepSeek Harness 的启动界面与启动动画插件。

基于原始开发者 **沈宏宏（[6shenhonghong9](https://github.com/6shenhonghong9)）** 的
[dsh-startup-screen](https://github.com/6shenhonghong9/dsh-startup-screen) 开发，
本增强版由 [Jam0731](https://github.com/Jam0731) 维护。保留上游提交历史与原作者署名，
原始代码和本版新增代码均采用 **[MIT License](LICENSE)**。完整来源与素材说明见 [NOTICE.md](NOTICE.md)。

本版新增：硅基流动声音源管理、原版与「少萝皇」两套预设、逐幕字幕与播报配置、
录音缓存与重新生成，以及 0.90～1.10 的合成语速数字输入框。

黑幕 DeepSeek 标识 → 过曝洗白 → 暖白「技术档案」底板 → 五步交互式访问授权 →
色散故障揭幕。

## 功能

**开机序列**　冷启动时播一段完整的开机动画，六幕连贯：厂牌标识 → 过曝洗白 →
暖白底板 → 五步授权 → 揭幕。中央一圈环形准星缓慢自转，缺口留在正下方，
不会挡住底部文字。

**可交互，不是播片**　第一、二步要你点按钮或按 Enter 才会继续（可以关掉）。
右上角有跳过按钮，Esc 也能跳。

**中文主字 + 英文等宽副标题**　英文副标题逐字打出来，像终端在接收数据。

**两套声音预设 + 自定义声音**　保留原版六段录音，新增「少萝皇」六段录音。两套预设均可离线播放。
填写自己的硅基流动 API key 后，可查看、创建和删除账户声音，并为六幕生成录音。
浏览器要求先有一次点击才准出声，所以点过按钮之后才会听到声音。

**原版就是原版**　选择「原版播报」会恢复原始六段录音、原始字幕与 1.00 倍速，不合成、不读取旧的合成覆盖缓存，也不自动回退到系统 TTS。原版字幕与录音为固定预设；此前的自定义台词和语速另存，切回其他声音时恢复。
如果云端已有同名声音，下拉框会将它标注为「原版播报（自定义音色）」；它与「系统预设」中的原版录音是不同来源。

**语音没播完不会推进**　每一步停留多久由实际音频时长决定。你点得快也不会把语音掐断。

**字幕与播报分开设置**　每幕可分别填写中文主字、英文副标题和实际播报文字。
预设保留中文画面、英文录音；实际播报文字留空时，生成该幕中文字幕对应的录音。

**同步和重新生成**　切换声音会自动保存并同步：已有录音直接使用，只生成缺失或文字变化的段落。
效果不满意时，可点「重新生成这一幕」或「全部重新生成」，强制调用接口。
新录音生成成功后才替换播放配置，失败保留旧录音；原版预设文件始终保留。

## 安装

在 [Releases](https://github.com/Jam0731/dsh-startup-screen/releases) 下载 `.tgz` 安装包。
本版沿用插件名 `dsh-startup-screen`；如已安装上游版本，先卸载同名插件再安装本版。
原有 `dsh-startup.json` 配置文件继续复用。

```bash
dsh plugin --profile web add ./dsh-startup-screen-1.2.2.tgz
```

Windows 上也可以解压 release 压缩包后**双击「安装.cmd」**，脚本会自动完成同样的操作。

**装完重启 dsh web**（关掉启动器窗口再重新双击）。重启后刷新页面就能看到启动动画，
设置页里会多出一项「启动动画」。

### 环境要求

| 项 | 要求 |
|---|---|
| 平台 | DSH **web** profile |
| Node | **>= 20** |
| 依赖 | 无（不需要 `npm install`） |

### 卸载

```bash
dsh plugin --profile web remove dsh-startup-screen
```

## 设置选项

装好后进入 **DSH 设置页 →「启动动画」**。

### 播放

| 选项 | 默认 | 作用 |
|---|---|---|
| 启用 | 开 | 总开关，关掉就完全不播 |
| 显示模式 | 每次会话 | `每次会话` 一个浏览器会话播一次 / `总是` 每次刷新都播 / `每天` 一天一次 |
| 主题 | 暖白 | `暖白` 参考片原色 / `暗色` 暗底板 |
| 速度 | 1× | 整段动画的快慢，0.35 – 3 倍 |
| 要求确认 | 开 | 第 1、2 步是否等你点按钮才继续 |
| 允许跳过 | 开 | 是否显示右上角跳过按钮、是否响应 Esc |

### 身份资料

| 选项 | 默认 | 作用 |
|---|---|---|
| 身份名称 | `JOYCE MOORE` | 终幕「欢迎 xxx 访问」里的名字 |
| 身份编号 | `0087` | 第二步身份卡上的编号，建议填数字 |
| 权限等级 | `3` | 第二步身份卡上的权限等级 |

### 语音

声音源区域支持以下操作：

1. 在「当前声音」中选择「原版播报」「少萝皇」或自己的云端声音。原版固定使用内置原始 MP3，不参与合成；其他声音按自定义台词同步录音。列表只显示名称，不展示声音 URI。
2. 保存 API key 后自动读取账户声音；「刷新我的声音」可重新获取。删除前在对应行确认；系统预设不能删除。
3. 展开「创建声音」，选择不超过 10 MB 的参考音频，填写音频原文。声音名称可自定义，留空使用文件名（含扩展名）。创建后自动为当前六幕生成录音并启用。
4. 选择少萝皇或自定义声音后，在「每幕字幕与录音」编辑文字，点「一键同步音色」或「保存」，再用各幕播放器试听。终幕可以用 `{identity}` 代表身份名称。原版的字幕、播报文字和合成语速不可编辑。
5. 某句效果不好时，点该幕「重新生成这一幕」；要重做整套则点「全部重新生成」。重新生成需要 API key，并会调用云端合成接口；原版播报不支持重新生成。
6. 「合成语速」通过数字输入框填写，范围为 0.90～1.10，默认 1.00，步进 0.01。失去焦点时自动修正越界值；后端也限制同一范围。调整后同步或重新生成；不同语速各自缓存，切回已有语速可直接复用。它与视觉动画速度、系统 TTS 试听语速分别设置。

接口模型固定为 `FunAudioLLM/CosyVoice2-0.5B`。接口只接受 ASCII 音色名称，插件会编码中文名称，并在列表还原显示；正常使用时不需要处理内部标识。

API key 只保存于本机 `DSH_HOME/startup-voices/credentials.json`（默认 `~/.dsh/`），不会写入插件、普通配置、启动页或前端存储。缓存位于同目录的 `cache/`；播放启动动画时不会调用云端生成。
未修改的两套预设不需要 API key。少萝皇修改台词或强制重新生成时，需要上传该预设的参考音频到当前账户并生成新录音。原版播报始终使用包内录音，不上传参考音频、不调用合成接口；缺失或读取失败时提示重新安装。

| 选项 | 默认 | 作用 |
|---|---|---|
| 语音播报 | 开 | 是否念台词 |
| 语音来源 | 本地录音 | 使用当前声音对应的预设或缓存录音 / `系统 TTS` 用浏览器合成音 |
| 音色 | 自动 | 只在用系统 TTS 时有效。留空 = 自动挑一个女声 |
| 语速 | 0.88 | 只在用系统 TTS 时有效。越慢越有旁白感 |
| 音调 | 0.85 | 只在用系统 TTS 时有效。调低更沉稳，1.0 以上会像客服播报 |
| 音量 | 0.9 | 台词音量 |
| 播报前提示音 | 开 | 念台词前先响两声轻提示，更像系统播报 |
| 开口前留白 | 240 ms | 提示音响过之后停多久再开口，0 – 1200 ms |

每幕以「实际播报文字」为准决定说什么；TTS 试听语言、音色、语速和音调只控制系统 TTS。正式录音不会随视觉速度加速。
前两幕同时等待用户确认（可关闭）和录音结束，后面各幕等待音频 `onended` 后再推进。终幕也会等欢迎录音结束后再揭幕；跳过或重播会停止旧录音。

### 界面音效

| 选项 | 默认 | 作用 |
|---|---|---|
| 界面音效 | 开 | 文字出现、阶段推进、按钮确认的「哒」声 |

| 音效来源 | 内置素材 | `内置素材` 用录音 / `现场合成` 用代码合成 |

| 选项 | 默认 | 作用 |

| 强调色 | `#ff7500` | 阶段条、进度条、准星的橙 |

### 文案

| 选项 | 默认 | 作用 |
|---|---|---|
| 品牌三行 | `DEEPSEEK` / `SYNTHESIZE INTELLIGENCE` / `HARNESS OS` | 左上角品牌块 |
| 黑幕三行 | `深度求索` / `DEEPSEEK` / `DEEPSEEK HARNESS` | 开场黑幕上的字 |

| 页脚 | `POWERED BY DEEPSEEK` | 右下角页脚 |
